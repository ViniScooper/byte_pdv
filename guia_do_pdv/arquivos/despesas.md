# Tela: Pagamentos e Saídas

Aqui você registra para onde o dinheiro está saindo. É essencial para que o fechamento do caixa no final do dia esteja correto.

## O que registrar aqui?

### 1. Pagamento de Fornecedores / Boletos
- Informe o valor, selecione o fornecedor cadastrado e anexe o comprovante.

### 2. Compras de Insumos (Entrada de Mercadoria)
Esta é uma função especial do PDV Byte:
- Ao preencher o valor e o motivo, você pode selecionar um **Produto** na seção "Atualizar Estoque".
- Informe a quantidade comprada.
- Ao salvar a despesa, o sistema **soma** automaticamente essa quantidade ao estoque do produto selecionado.

### 3. Sangrias (Retirada de Lucro/Dinheiro)
- Use o motivo "Sangria / Retirada de lucro" para registrar quando você tira dinheiro da gaveta para levar ao banco ou para uso pessoal.

## Funcionalidade de Anexo (Fotos)
- Clique na área de "Nota Fiscal / Comprovante" para subir uma imagem.
- Se estiver usando o celular, o sistema abrirá a câmera para você tirar a foto na hora.
- Essa foto ficará guardada na galeria para conferência posterior.

> [!IMPORTANT]
> Nunca retire dinheiro da gaveta sem registrar nesta tela, caso contrário haverá "furo" no fechamento do caixa.
